# WFW430 Control Center — Web MVP

واجهة ويب عربية RTL مبنية من مصنف `WFW430_Control_Center.xlsx` لتشغيل ومتابعة المعرض.

## الوحدات
- لوحة تحكم حسب التاريخ.
- المتابعة اليومية للموظفين.
- سجل الحالات والأخطاء مع تصنيف السبب.
- قاعدة المعرفة قبل التصعيد للمشرف أو 777.
- مرجع العروض.
- إغلاق الشفت وحساب الفرق تلقائيًا.
- دليل الموظفين.
- إعدادات حدود الأخطاء والأوزان.
- تصدير CSV ونسخة احتياطية JSON.
- PWA بسيطة تعمل Offline بعد أول تحميل.

## التشغيل محليًا
أي خادم ملفات ثابت يكفي. مثال:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## حدود النسخة الحالية
البيانات تحفظ في `localStorage` على نفس الجهاز/المتصفح. هذه النسخة مناسبة كـ MVP وتجربة التشغيل. للاستخدام المتزامن بين الموظفين نحتاج Backend (مثل Supabase/Postgres) مع Authentication وRBAC وسجل تدقيق.

## منطق مطابق للمصنف
- حالة الموظف: مستقر / تنبيه-تدريب / مراجعة عاجلة بناءً على حدود الأخطاء.
- إغلاق الشفت: الفرق = الإجمالي الفعلي − إجمالي النظام.
- صفر = مطابق، |الفرق| <= 1 = فرق بسيط، غير ذلك = مراجعة عاجلة.
- لا توجد درجة أداء نهائية في هذه المرحلة؛ المؤشرات للمراجعة فقط.
